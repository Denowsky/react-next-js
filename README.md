
# Инструкция по запуску:
* Установить с оф.сайта Node.js 18 и npm/yarn/pnpm
* Клонировать репозиторий git clone https://github.com/Denowsky/react-next-js и переход в каталог приложения через bash
``cd book-catalog``
* Установка react: ``npm install``
* Запуск приложения: ``npm run dev``

# Главная страница
* Просмотр книг: На главной странице отображается список книг, загруженных из API

* Поиск: Используйте поле поиска для фильтрации книг по названию или автору

* Добавление книги: Заполните форму вверху страницы и нажмите "Добавить книгу"

* Удаление книги: Нажмите кнопку "Удалить" на карточке книги

* Детальный просмотр: Нажмите "Подробнее" или на название книги для перехода на детальную страницу
